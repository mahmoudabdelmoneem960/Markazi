# مجلد الواجهة الأمامية (Frontend)

هذا المجلد يحتوي على كافة ملفات الواجهة الخاصة بتطبيق **Markazi**، بما يشمل قوالب الـ HTML وصفحات العرض وملفات الـ CSS وكود الـ JavaScript للعميل. تم فصل هذا المجلد لتسهيل تصفح وتعديل ومراجعة كود الواجهة بمعزل عن كود الباك إند ومنطق التوزيع.

---

## 📁 هيكل المجلد

```
frontend/
├── templates/              # قوالب HTML (Jinja2)
│   ├── base.html           # القالب الأساسي (شريط التنقل، الهيدر، تحميل المكتبات)
│   ├── dashboard.html      # صفحة التشغيلات الرئيسية وقائمة التوزيعات
│   ├── run_new.html        # صفحة رفع الشيتات والفحص المسبق والبدء
│   ├── run.html            # صفحة نتائج التشغيل (الخرائط، المقاعد، التحميلات)
│   ├── centers.html        # صفحة إدارة مراكز التدريب وتعديل الإحداثيات
│   ├── review.html         # صفحة مراجعة وتصحيح مواقع الطلاب والعناوين
│   ├── compare.html        # صفحة المقارنة بين تشغيلين
│   ├── settings.html       # صفحة الإعدادات وتغيير كلمة السر وحالة السيستم
│   ├── login.html          # صفحة تسجيل الدخول
│   └── setup.html          # صفحة إنشاء حساب الأدمن الأول
└── static/
    ├── css/
    │   └── app.css         # التنسيقات الرئيسية (الألوان، البطاقات، الجداول، دعم RTL)
    └── js/
        ├── common.js       # الدوال المساعدة المشتركة، استدعاء الـ API، والتنبيهات
        ├── map.js          # إعداد وتجهيز خرائط Leaflet التفاعلية
        ├── dashboard.js    # منطق صفحة التشغيلات وعرض المؤشرات
        ├── run_new.js      # منطق رفع الملفات وفحصها وبدء تشغيل التوزيع
        ├── run.js          # متابعة تقدم التشغيل، وعرض الخريطة والجداول والـ VP
        ├── centers.js      # إدارة خريطة المراكز، فحص لينكات جوجل، وتصدير البيانات
        ├── review.js       # مراجعة عناوين الطلاب وتعديل المواقع يدوياً
        ├── compare.js      # مقارنة تشغيلين وتحليل تنقلات الطلاب
        └── settings.js     # حفظ واسترجاع إعدادات النظام وفحص OSRM
```

---

## 💡 كيف تتصل الواجهة بالباك إند؟

- تعتمد كل صفحات الواجهة على إرسال واستقبال البيانات بصيغة **JSON** عبر الـ API الموجود في السيرفر تحت المسار `/api/*`.
- يتم استخدام الدالة المساعدة `api(endpoint, options)` الموجودة في `frontend/static/js/common.js` لعمل جميع طلبات الـ HTTP (`GET` و `POST`) بشكل موحد ومعالجة رسائل الخطأ والتنبيهات.

---

## 🔍 مراجعة وتعديل كود الواجهة

1. **تعديل تصميم صفحة معينة:**
   - ابحث عن القالب المقابل لها داخل `frontend/templates/`.
   - افتح ملف الـ JS المقابل في `frontend/static/js/` لرؤية كيفية جلب البيانات وتحديث الـ DOM.
2. **تعديل الأنماط والألوان (CSS):**
   - كافة المتغيرات والأنماط موجودة في `frontend/static/css/app.css`.
