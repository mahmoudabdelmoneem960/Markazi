# مجلد الباك إند (Backend)

هذا المجلد يحتوي على منطق الخادم (Python / Flask)، خوارزمية التوزيع الجغرافي، قاعدة البيانات، والـ API الخاص بتطبيق **Markazi**.

---

## 📁 هيكل المجلد

```
backend/
├── distributor/             # حزمة بايثون الأساسية (Core Logic)
│   ├── __init__.py          # تهيئة تطبيق Flask وربطه بمجلدات الفرونت إند
│   ├── config.py            # إعدادات السيستم والمسارات والمتغيرات
│   ├── auth.py              # نظام تسجيل الدخول والجلسات والأدمن
│   ├── db.py                # التعامل مع قاعدة بيانات SQLite وسجلات التعديل
│   ├── jobs.py              # إدارة المهام الخلفية ومتابعة تقدم التشغيل
│   ├── core/                # محرك التوزيع وتحديد المواقع
│   │   ├── engine.py        # خوارزمية التوزيع على المراكز
│   │   ├── geocoder.py      # تحديد إحداثيات الطلاب من العناوين بدون إنترنت
│   │   ├── geonorm.py       # معالجة النصوص والمناطق العربية
│   │   ├── geoprep.py       # تجهيز وتوحيد الإحداثيات والتحقق منها
│   │   ├── googlegeo.py     # فحص وتصحيح المراكز بـ Google API (اختياري)
│   │   └── locdb.py         # قاعدة بيانات الأماكن والمراكز
│   ├── services/            # خدمات معالجة وتصدير البيانات
│   │   ├── centers.py       # خدمة إدارة المراكز
│   │   ├── compare.py       # خدمة مقارنة التشغيلات
│   │   ├── exports.py       # تصدير ملفات Excel و QGIS
│   │   ├── preflight.py     # الفحص المسبق للشيتات المرفوعة
│   │   ├── runs.py          # إدارة وحفظ التشغيلات
│   │   ├── sheets.py        # قراءة وتفسير شيتات الطلاب والمراكز
│   │   └── whatif.py        # تحليل المقاعد المقترحة (What-if)
│   └── web/                 # طبقة التوجيه (Controllers)
│       ├── api.py           # واجهات الـ REST API لجميع العمليات
│       └── pages.py         # توجيه وعرض صفحات الـ HTML
├── tests/                   # اختبارات النظام التلقائية (pytest)
├── requirements.txt         # متطلبات ومكتبات الباك إند
├── pytest.ini               # إعدادات الاختبارات داخل مجلد الباك إند
├── run.py                   # ملف بدء تشغيل السيرفر من الـ Terminal
└── run.bat                  # ملف تشغيل سريع لويندوز
```

---

## 🚀 تشغيل الباك إند من الـ Terminal

يمكنك فتح Terminal مخصص للباك إند والتشغيل مباشرة بالأوامر التالية:

```bash
cd backend
python run.py
```

أو استخدام البيئة الافتراضية إذا كانت مثبتة في المجلد الرئيسي:

```bash
cd backend
..\.venv\Scripts\python run.py
```

أو النقر المزدوج على ملف `run.bat` داخل مجلد `backend`.

السيرفر سيعمل على:
`http://127.0.0.1:5000`

---

## 🧪 تشغيل الاختبارات (Tests)

لتشغيل جميع اختبارات الباك إند:

```bash
cd backend
python -m pytest
```
